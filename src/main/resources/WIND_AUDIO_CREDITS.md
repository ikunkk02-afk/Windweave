# Windweave audio attribution

Source: **wind whoosh loop**, by **SketchMan3**, published 2019-07-16.

Asset page: https://opengameart.org/content/wind-whoosh-loop

Original download: https://opengameart.org/sites/default/files/wind%20woosh%20loop.ogg

License shown on the asset page: **CC0 1.0**, https://creativecommons.org/publicdomain/zero/1.0/

Retrieved 2026-10-31. The source author describes this as a loop edited and EQ'd from Loopable Dungeon Ambience.

Windweave's wind_loop.ogg and sandstorm_loop.ogg are filtered, level-adjusted mono derivatives of that file, with a 0.5-second circular crossfade for seamless playback. No additional third-party audio is mixed in. The mod's code license does not override the CC0 status of these sounds.

Processing is reproducible using scripts/prepare-wind-audio.ps1; the SHA-256 of the downloaded original is recorded in that script's adjacent audio-source.json.
